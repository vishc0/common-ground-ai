# Common Ground AI

Common Ground AI is a free public problem-solving network. People ask questions with limited, non-identifying context; AI proposes structured solutions; communities evaluate, improve, and connect those solutions into a living knowledge graph—the Tree of Life.

## Three modules

1. **Ask** — post a question, review up to five AI-suggested tags, receive a transparent solution brief, and evaluate it.
2. **Explore** — search question text or tags, page through results, rate answers, and join screened discussions.
3. **Tree of Life** — inspect an initial five-level 2D map from human needs to domains, tag spaces, clusters, and question leaves.

The current application is an interactive front-end prototype. Its AI response and public questions are sample data; profiles, votes, and comments remain only in the current browser. The prototype safety screen is a client-side heuristic and must be replaced by server-side layered moderation before public submission is enabled.

## Run locally

Serve the `dist/` directory with any static HTTP server. There is no build step.

## Product commitments

- Core participation stays free for individuals.
- No sale of personal profiles or private question histories.
- Popularity does not equal truth, safety, or fairness.
- Dissent and minority experiences remain visible.
- The project stores concise public rationales—not private model chain-of-thought.
- Model and infrastructure providers remain replaceable.
