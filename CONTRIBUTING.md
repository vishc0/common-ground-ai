# Contributing

Common Ground AI is at the prototype stage. Before accepting production code, the project will establish its license, governance, safety constitution, moderation process, and contributor decision rights.

For now:

1. Open an issue describing the user problem, affected module, safety implications, and smallest testable change.
2. Do not submit real personal, medical, financial, legal, or identifying data.
3. Keep changes accessible, mobile-first, provider-neutral, and easy to operate.
4. Include tests for tag limits, authorization, privacy, moderation, or ranking behavior when relevant.
5. Never add secrets, API keys, scraped personal data, or generated private chain-of-thought.

By participating, treat disagreement as product evidence—not a reason to attack another contributor.
